# 🧠 AI Personal Life Manager – Concierge Agent
A multi-agent AI system that helps users manage daily tasks, reminders, travel plans, expenses, and personal preferences using a clean modular architecture.

---

## 🚀 Features
- 📝 Task Management Agent  
- ⏰ Reminder Agent  
- 🚗 Travel Planning Agent  
- 💰 Expense Tracking Agent  
- 🧩 Memory Agent (stores user preferences)  
- 🤝 Central Coordinator Agent that routes requests  
- 📜 Logger for clean demo outputs

## 🏗️ How It Works
The system uses **multi-agent architecture**:

### 🟦 1. Coordinator Agent
Routes user messages to the right specialist agent.

### 🟩 2. Specialist Agents
- TaskAgent → Adds tasks  
- ReminderAgent → Sets reminders  
- TravelAgent → Suggests travel options  
- ExpenseAgent → Logs expenses  
- MemoryAgent → Stores personal preferences
